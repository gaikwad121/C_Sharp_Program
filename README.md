🎲 Dice Challenge – C#

A simple and interactive C# console game where the player competes against a randomly generated target number. Roll the dice and see if you can beat the challenge!

✨ Features
🎯 Randomly generated target numbers
🎲 Random dice rolls
🏆 Win and lose conditions
🔄 Replay option
💻 Console-based interface
🎉 Fun emoji-based game output
🚀 How to Play
Run the C# program.
The game generates a random target number.
The dice is rolled automatically.
Your dice result is compared with the target number.
If you beat the target, you win; otherwise, you lose.
Choose yes to play again or no to end the game.
🛠️ Technologies Used

Console Application

Console input/output
